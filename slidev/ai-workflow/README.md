# AI 開發流實戰 — Slidev 簡報

## 本地啟動

```bash
cd slidev/ai-workflow
npm install
npm run dev
```

開啟瀏覽器：http://localhost:3030

## 指令

| 指令 | 說明 |
|------|------|
| `npm run dev` | 啟動本地開發伺服器（含 hot reload） |
| `npm run build` | 建置靜態檔案到 `dist/` |
| `npm run export` | 匯出為 PDF |
